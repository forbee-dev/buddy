# Buddy Companion

Companion extension for the Buddy macOS app. It connects to `~/Library/Application Support/Buddy/buddy.sock`. It types prompts into, and focuses, integrated terminals on request.

## Install

    code --install-extension vscode-ext/buddy-companion-0.1.1.vsix
    cursor --install-extension vscode-ext/buddy-companion-0.1.1.vsix

## Build

    npm install
    npm run build
    npm test
    npm run package
